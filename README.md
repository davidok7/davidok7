# 고현석 · NEO AGENT

**1인 대표의 반복 업무를 AI 직원에게 넘기는 일을 합니다.**

공공데이터와 AI 에이전트를 붙여, 기획부터 배포까지 혼자 끝내는 프로토타입을 만듭니다.
코드는 짧게, 검증은 브라우저에서 직접. 화면에 없는 수치는 쓰지 않습니다.
